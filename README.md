# pl-insert-3d

FS5 시료실 안쪽을 줄자와 사진에서 읽은 값으로 그린 검토용 3D 모델입니다(v16, 2026-11-20). 제작 도면이 아닙니다.

- 시료실 안: 바닥, 벽, 렌즈 창 2개(여기광 왼쪽, 검출 오른쪽), 검은 종이 가림막 2장, 스테이지 받침과 시료, 초점 봉과 커플링
- 넣으려는 것: 앞쪽 바닥판 2장(두께 6 mm)과 짧은 쐐기, 판 위에 세우는 조명부용 기둥과 조명부(후보 자리, 미정)
- 치수는 측정 / 가정 / 후보로 나누어 표시했고, 아직 못 잰 값은 페이지에 적었습니다.
- 앞쪽 판과 쐐기는 3 mm 시험 판 치수를 쓰되 두께만 6 mm로 바꾸고, 가림막 쪽 대각선 자르기를 키웠습니다.

보는 법: 한 손가락으로 돌리고 두 손가락으로 확대·이동합니다. 부품을 누르면 이름과 치수 출처가 나옵니다. 이전 판(v6 ~ v15)은 커밋 기록에 있습니다.
